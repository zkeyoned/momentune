# 调研 music-lib 汽水音乐歌单支持 Spec

## Why
momentune 项目的音乐库策略中，汽水音乐作为"免费听全部可兜底"的平台是重要一环。需要确认 `github.com/guohuiyuan/music-lib`（Go 库）对汽水音乐（soda 平台）的歌单搜索能力，以评估是否可复用其接口为项目接入汽水歌单数据（按关键词搜歌单、获取收藏量/播放量、解析歌单全部歌曲）。

## What Changes
- 调研 `guohuiyuan/music-lib` 仓库中 `soda` 包的源码，确认以下三项能力的实际接口与数据结构：
  1. 按关键词搜索汽水歌单的函数签名、入参、返回结构
  2. 搜索结果中是否包含歌单收藏量/播放量字段
  3. 解析歌单内全部歌曲的函数签名与返回结构
- 搭建 Go 最小测试环境，用关键词"痛苦说唱"实际调用汽水歌单搜索接口，打印原始返回结果
- 若歌单搜索不可用，则检查 soda 包源码中所有已接入的接口，列出可复用的搜索类接口
- 输出调研结论报告（含原始测试输出）

## Impact
- Affected specs: 无（纯调研任务，不修改 momentune 任何代码）
- Affected code: 无（仅在临时目录搭建 Go 测试环境，不污染项目代码库）
- 调研结论将用于后续决定是否将汽水歌单搜索接入 momentune 的音乐库构建流程

## ADDED Requirements

### Requirement: 汽水歌单搜索能力确认
调研 SHALL 确认 `music-lib/soda` 包是否提供按关键词搜索歌单的公开函数。

#### Scenario: 歌单搜索可用
- **WHEN** 调用 soda 包的歌单搜索函数，传入关键词"痛苦说唱"
- **THEN** 返回歌单列表，每项包含歌单 ID、名称、创建者等基本信息

#### Scenario: 歌单搜索不可用
- **WHEN** soda 包没有公开的歌单搜索函数
- **THEN** 列出 soda 包中所有已接入的接口，标注哪些可复用于搜索场景

### Requirement: 歌单收藏量/播放量字段确认
调研 SHALL 检查歌单搜索结果的数据结构，确认是否包含收藏量（collection count）和/或播放量（play count）字段。

#### Scenario: 字段存在
- **WHEN** 检查歌单结构体定义
- **THEN** 明确列出收藏量/播放量字段的名称与类型

#### Scenario: 字段不存在
- **WHEN** 歌单结构体中无收藏量/播放量字段
- **THEN** 明确说明缺失，并检查原始 API 响应 JSON 中是否有这些字段未被映射到结构体

### Requirement: 歌单歌曲解析能力确认
调研 SHALL 确认 `music-lib/soda` 包是否能解析指定歌单的全部歌曲。

#### Scenario: 解析可用
- **WHEN** 传入歌单 ID 或歌单链接
- **THEN** 返回该歌单内全部歌曲列表，每首歌曲包含 ID、名称、歌手、时长等基本信息

### Requirement: 最小实测验证
调研 SHALL 搭建 Go 最小测试环境并实际运行，用关键词"痛苦说唱"搜索汽水歌单。

#### Scenario: 测试成功
- **WHEN** 运行最小测试程序
- **THEN** 打印搜索结果的原始 JSON 或结构化输出，供用户审阅

#### Scenario: 测试失败（接口不可用/需登录/风控拦截）
- **WHEN** 测试程序运行失败
- **THEN** 记录错误信息，分析失败原因（是否需要 Cookie、是否被风控拦截等），并给出后续建议
