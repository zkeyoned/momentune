# 修复：网易云扫码登录失败（2 个 bug 导致）

## 问题诊断

通过终端日志分析，发现 2 个 bug 叠加导致扫码登录流程失败：

### Bug 1: 前后端 code 不一致（P0）

- **后端** `qr-check.ts:67` 登录成功后返回 `{ code: 0, cookie, nickname, uid }`
- **前端** `PlatformQRModal.tsx:94` 判断条件是 `result.code === 803`
- 结果：扫码成功后端返回 `code: 0`，前端永远进不了成功分支

### Bug 2: 轮询在扫码成功后没有正确停止（P1）

- 扫码成功 803 后，useEffect 因 stage 变化触发 cleanup → re-create
- 新 effect 运行时 stage 可能还是 'scanned'（React batch 导致 setStage 异步），重新满足条件启动轮询
- 拿到 `code: 800`（二维码已过期，因为已被消费），把 stage 覆盖成 'expired'
- 用户看到"二维码已过期"而不是登录成功

### Bug 3: 诊断日志需要清理（P2）

- `qr-check.ts` 和 `vite.config.ts` 里有调试用的 `console.log`，正式版不需要

## 修复方案

### 修复 1: 统一 code 为 803

**文件**: `api/netease/qr-check.ts:67`
```ts
// 改前
jsonBody(res, 200, { code: 0, cookie, nickname, uid });
// 改后
jsonBody(res, 200, { code: 803, cookie, nickname, uid });
```

### 修复 2: 轮询停止机制

**文件**: `src/app/components/PlatformQRModal.tsx`

添加一个 `loginCompletedRef` ref，在拿到 803 时标记为 true，poll 函数开头检查：

```ts
const loginCompletedRef = useRef(false);

// poll 函数开头
const poll = async () => {
  if (loginCompletedRef.current) return;  // 已完成,不再轮询
  // ...
  if (result.code === 803 && result.cookie) {
    loginCompletedRef.current = true;     // 标记完成
    // 继续处理登录成功
  }
};
```

### 修复 3: 清理诊断日志

**文件**: `api/netease/qr-check.ts` — 删除 3 行 `console.log`
**文件**: `vite.config.ts` — 删除 2 行 `console.log`
